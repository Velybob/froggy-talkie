# Доставка модели

Приложение и веса распространяются отдельно. GUI загружает файлы напрямую с
Hugging Face после явного нажатия пользователя; платных API и токенов нет.

- Репозиторий: https://huggingface.co/FluidInference/parakeet-ultra-coreml
- Закреплённая ревизия: `95eaa59a39d4394f047a4dc5cce480388a60d1b6`.
- Состав: 20 файлов, **632 314 500 байт** (~603 MiB).
- Манифест: `Sources/DictationModels/Resources/parakeet-ultra.json`.
- SHA-256 всех файлов проверены по закреплённому upstream: LFS SHA-256 для LFS,
  Git blob ID для обычных Git-файлов; затем сохранены единые SHA-256 для клиента.
- Лицензия: CC BY 4.0. Атрибуция и полный текст находятся в `Licenses/Parakeet`
  и `THIRD_PARTY_NOTICES.md`. Веса не изменялись этим проектом.

Загрузка потоковая, не держит 632 МБ в одном объекте Data. Сетевой сеанс не
использует постоянный кеш, cookies или хранилище учётных данных. GUI принимает
только HTTPS, включая перенаправления CDN. Каждый файл проверяется по размеру
и SHA-256, весь набор устанавливается после проверки во временной соседней
папке. Ошибка или отмена не заменяет прежнюю модель; временная папка удаляется
при обычном завершении операции. При аварийном выходе она может остаться.
Уже проверенные файлы существующей установки используются повторно; докачка
части одного файла после обрыва пока не поддерживается. При ремонте прежняя
папка сохраняется под именем `parakeet-ultra-coreml-previous-UUID`.

Путь по умолчанию: `~/Library/Application Support/Froggy Talkie/Models`.
Сохранённый пользовательский путь имеет приоритет; старый development-каталог
`Models` продолжает распознаваться. Кнопка загрузки устанавливает веса в
Application Support и меняет сохранённый путь только после успешной установки.

## Установка через командную строку

Необязательный путь для разработчиков, Python 3.9+, без внешних Python-пакетов:

```sh
python3 scripts/download_models.py
# Или отдельная папка и её последующий выбор в настройках:
python3 scripts/download_models.py --directory ./Models
python3 scripts/download_models.py --directory ./Models --verify-only
```

`--verify-only` не обращается к сети и не изменяет файлы.
Манифест содержит фиксированную ревизию и проверочные суммы, а не `main`.
Изменение модели требует осознанного обновления манифеста и повторных проверок.
