# Froggy Talkie

Локальная диктовка на русском и английском для **macOS 15+ и Apple Silicon**.
Удерживайте выбранное сочетание клавиш, говорите, отпустите — текст появится в
поддерживаемом поле ввода. Можно записывать вручную или открывать аудиофайлы до
трёх минут. Модель Parakeet Ultra работает на Mac; текст и аудио не отправляются
на сервер распознавания.

Версия исходников: **0.5.0 (17), beta 2**. Собственный код и иконка распространяются по
[MIT](LICENSE); зависимости и модель имеют отдельные условия:
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Beta 2 распространяется как prerelease для проверки на другом Mac.

**[Скачать 0.5.0 beta 2 для Mac с Apple Silicon](https://github.com/Velybob/froggy-talkie/releases/download/v0.5.0-beta.2/Froggy-Talkie-0.5.0-beta.2-macos-arm64-preview.zip)** ·

См. [инструкцию установки](docs/INSTALL.md). Для распознавания потребуется
однократно загрузить **632 314 500 байт (~632 МБ)** из Hugging Face через
**Настройки → Загрузить модель**. После загрузки интернет для диктовки не нужен.
Веса не входят в Git и архив приложения. [Подробнее о модели](docs/MODELS.md).

Архив с суффиксом `preview` подписан ad-hoc и **не нотарифицирован**. Такая
подпись не подтверждает разработчика для Gatekeeper. Для первого запуска может
потребоваться «Всё равно открыть» в настройках конфиденциальности и безопасности
macOS; политика управляемого устройства может запрещать такой запуск.

## Сборка из исходников

Нужен Mac с Apple Silicon, macOS 15+ и Command Line Tools с **Swift 6.1.2**
(проверенная версия, SDK macOS 15.5). Полный Xcode для локальной сборки не нужен.
Скриптам экспорта и проверки нужен Python 3.9+. Зависимости закреплены в
`Package.swift` и `Package.resolved`; первое разрешение зависимостей требует сети.

```sh
xcode-select --install  # только если Command Line Tools ещё не установлены
swift --version
zsh scripts/build_release.sh
```

Скрипт создаёт **отдельный** `release/0.5.0/Froggy Talkie.app`, ZIP и SHA-256.
Он не устанавливает приложение, не меняет `dist/`, не создаёт сертификаты и не
читает приватные ключи в режиме preview. Повторная сборка в тот же выходной
каталог запрещена, чтобы сохранить предыдущий результат:

```sh
zsh scripts/build_release.sh --output /tmp/froggy-build-2
```

В рабочем каталоге разработчика могут находиться локальные зеркала SwiftPM.
Они не включаются в экспорт. Обычная сборка из чистого экспорта получает
зависимости по публичным URL. Повторяемость означает закреплённые версии,
ресурсы и команды; побайтовое совпадение Mach-O/ZIP между разными SDK и
подписями не гарантируется.

## Проверки

```sh
swift test --cache-path .cache/spm --config-path .cache/config \
  --security-path .cache/security --disable-automatic-resolution
# Дополнительно: реальная загрузка одного файла модели размером 243 байта.
FROGGY_TEST_NETWORK=1 swift test --cache-path .cache/spm \
  --config-path .cache/config --security-path .cache/security \
  --disable-automatic-resolution --filter pinnedHTTPSDownload
python3 scripts/verify_release.py "release/0.5.0/Froggy Talkie.app"
"release/0.5.0/Froggy Talkie.app/Contents/MacOS/LocalDictation" --check-resources
```

Тесты не включают микрофон и не вставляют текст в другие приложения. Проверка
буфера обмена использует отдельный тестовый pasteboard, проверка хоткея
временно регистрирует редкие четырёхмодификаторные F18/F19. Режим
`--check-resources` завершается до создания GUI, регистрации хоткея, чтения
настроек, загрузки ASR и запросов сети.

Для визуальных проверок без микрофона см. [DEVELOPMENT.md](docs/DEVELOPMENT.md).
Для этой beta ещё предстоит проверка скачанной сборки на другом Mac, реального
микрофона, хоткея и вставки; проверки в рабочем каталоге её не заменяют.

## Поведение и ограничения

- Сочетание настраивается в **Настройки → Диктовка → Изменить**. Изначальное
  `⌃⌥Пробел` может конфликтовать с переключением раскладки. Физические коды
  клавиш сохраняются при смене RU/EN.
- Разрешение микрофона запрашивается при первом открытии окна, если решение
  ещё не принято; запись начинается только по кнопке или хоткею. При ручной
  записи «Завершить и распознать» останавливает микрофон и выводит текст в окне;
  остановка также доступна в плавающей панели.
- Для вставки нужен «Универсальный
  доступ». Отдельный Input Monitoring не запрашивается. Поля паролей исключены.
- Перед вставкой повторно проверяются приложение, поле и доступное выделение.
  Для Electron/Chromium при необходимости включается дерево доступности и
  выполняются ограниченные повторные запросы поля; без подтверждённого поля
  автоматической вставки нет.
  Некоторые редакторы не сообщают положение каретки; в них перемещение внутри
  того же поля обнаружить нельзя. Некоторые редакторы не поддерживают вставку.
- Буфер обмена сохраняется до 16 MiB и восстанавливается через 0,5 с, если за это
  время никто его не изменил. Очень медленный редактор может не успеть обработать
  Cmd+V. Статус «Передан» означает отправку события, а не подтверждение редактора.
  Return/отправка сообщения не синтезируются. Результат доступен в окне.
- Отмена не всегда мгновенно останавливает уже начатый вызов Core ML. До его
  завершения новая операция заблокирована, отменённый результат не вставляется.
- Текст не сохраняется в историю. Временный CAF удаляется после обработки,
  отмены и обычного выхода; аварийный выход может оставить файл в системном
  временном каталоге. Исходный импортированный аудиофайл не удаляется.
- Темы: системная, светлая и тёмная. Автозапуск можно включить средствами macOS;
  приложение не добавляет себя в объекты входа автоматически.

## Для разработчиков

GUI использует только FluidAudio/Parakeet. WhisperKit подключён к отдельному
`asr-bench`; он не входит в граф зависимостей GUI. Локальные записи, исследовательские
данные и результаты измерений не входят в публикуемый комплект.
